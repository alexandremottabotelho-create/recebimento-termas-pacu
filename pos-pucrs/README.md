# Pós PUCRS — Base de conhecimento aplicada

Material de estudo da pós-graduação organizado para uso prático na operação do
Termas Pacu e nos projetos deste repositório (app de Validação de Recebimento,
planilha `CONFERENCIA`, Power BI).

## Como esta pasta funciona

| Camada | Arquivo | Para que serve |
|---|---|---|
| Conteúdo | `<disciplina>/aula-NN.md` | Resumo fiel de cada aula: conceitos, métodos e exemplos do professor |
| Aplicação | `<disciplina>/aplicacao-termas-pacu.md` | Como cada conceito vira rotina, indicador ou funcionalidade no nosso contexto |
| Execução | `backlog-aplicacao.md` | Lista priorizada do que construir ou implantar a partir das aulas |

Regra: o resumo da aula registra o que o professor ensinou; a aplicação registra
o que nós decidimos fazer com isso. Não misturar.

## Como adicionar material novo

1. Enviar o PDF da aula na conversa.
2. Criar `aula-NN.md` na pasta da disciplina (nova disciplina = nova pasta).
3. Atualizar `aplicacao-termas-pacu.md` da disciplina com os conceitos aplicáveis.
4. Incluir no `backlog-aplicacao.md` o que virar ação.

## Observações

- Os PDFs originais das aulas não estão versionados aqui: são material autoral
  do curso. Ficam apenas os resumos próprios.
- Gráficos e imagens dos slides não foram transcritos; só o texto.
